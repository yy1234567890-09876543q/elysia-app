## 1. 快速开始

1. 打开 App → **设置 → 服务商** → 「＋ 添加」
2. 填任意 **OpenAI 兼容**的服务商：`BaseURL`（如 `https://api.deepseek.com/v1`）、`API Key`，保存
3. 点「**获取模型**」把模型列表拉下来，挑一个
4. **设置 → 助手**：填名字、人格提示词、台词语录、头像（可选）
   - ⚠️ **名字必填**，而且**「角色卡（人格）」和「技能包」至少要有一个** —— 不然保存按钮是灰的（弹窗顶上会写清楚还差什么）
   - 人格可以手写、可以「**导入角色卡**」（JSON / PNG / 纯文本都吃）、也可以一键「**用全局人格**」
5. 回到**消息列表**，点她那一行开聊 ✓

> 聊天页顶部药丸显示当前「模型 / 服务商」，点它随时换模型；右边显示余额（若服务商支持查询余额接口）。

## 2. 界面总览（微信风）

打开 App 第一眼是**消息列表**（底下四个标签页）：

| 标签 | 里面是什么 |
|---|---|
| **Elysia**（第一格，名字就是 App 名） | **消息列表**：一个 AI 一行，显示头像、名字、最后一句、时间（今天＝时:分 / 昨天 / 一周内＝星期几 / 更早＝月日）。点一行进聊天；**长按**可以重命名 / 删除 |
| **通讯录** | 助手列表：点谁就跟谁聊 |
| **发现** | 朋友圈（她的签名墙）· 一起听歌 · 礼物商店 · 五子棋比赛 · 统计 |
| **我** | 你的页面：头像、昵称、微信号、服务、收藏、朋友圈、设置 |

**「我」页面**
- 点头像换头像；点昵称那一行可以改**昵称和微信号**
- **服务** → 微信那个「服务」页：绿卡里有**收付款**和**钱包**（右边直接显示余额），下面是**金融理财**（理财通＝去赚钱）和**生活服务**（一起听歌 / 礼物商店 / 五子棋 / 转账说明）
- **朋友圈** = 你的签名墙；**收藏** = 礼物盒（她送你的 + 你送她的礼物都收在里面）
- **设置** = 原来的设置页

**聊天页**：左上 `‹` 回消息列表、`☰` 开抽屉（会话列表 / 设置 / 统计）、`✎` 清空这段聊天（会先问你一句）。

## 3. 聊天基础

| 功能 | 怎么用 |
|---|---|
| 发消息 | 底部输入框，Enter 或右边按钮发送 |
| 发图片 / 文件 | 输入框左边「＋」→ 图片 / 文件（图片会以多模态方式发给模型） |
| 停止生成 | 生成过程中发送键变成「停止」 |
| 重新生成 | 最后一条回复下方「重新生成」；或长按某条用户消息 → 从这儿重新生成 |
| 编辑 | 长按自己的消息 → 编辑 |
| **撤回** | 长按自己的消息 → 撤回：那条会变成一行灰字「你撤回了一条消息」，**不会连累它的回复**；撤回的内容不会再发给模型，统计也不计入 |
| 删除 | 长按消息 → 删除（**钱的消息只能删除，且删除不动余额**） |
| 复制 | 长按 → 复制，或回复下方「复制」按钮 |
| 时间显示 | 默认「间隔 ≥5 分钟 / 跨天」才插一条时间分隔；**设置 → 聊天显示**里可开「每条消息都显示时间」 |
| 键盘自动上滑 | 点输入框弹出键盘时，聊天会自动滚到最新消息，不会被键盘挡住 |
| 聊天页右滑 | **往右滑聊天屏幕 = 进入统计页**（跟手滑动，滑过约 1/5 屏即切换） |

**「＋」菜单里有什么**：图片 · 文件 · 💸 转账 · 🏦 借钱 · 💰 还钱 · ⚫ 五子棋比赛 · 🎧 一起听歌 · 🎁 礼物商店

> **一个 AI 只有一段会话**：换助手就切到她自己那一段（以前同一角色的零散会话会被自动合并成一段）。
> 想从零开始聊，点 `✎`「清空这段聊天」—— **只删聊天记录，她对你的记忆、好感度、心情都还在** ✓

## 4. 多助手（人格）系统

- 每个助手有**独立**的：人格提示词、头像、台词语录、首选服务商/模型/温度、绑定的技能包
- **一个助手 = 一段会话**，切助手就是切到那一段
- **新建助手**的规矩：名字必填，且「角色卡（人格）」与「技能包」二选一必须有一个（弹窗顶上会提示还差什么）
- 从消息列表点 **⊕** 会**直接跳到「新建助手」**；建好之后自动切过去并进聊天
- **删除助手 = 连它的全部数据一起删**（会先弹确认框）：长期/短期记忆、心情、好感度、欠条、签名墙、它排的提醒、点赞记录、它的存款、它的会话、礼物记录

## 5. 记忆系统

两层记忆，都会自动带进对话（不需要你手动喂）：

| 层 | 记什么 | 怎么来 |
|---|---|---|
| **长期记忆** | 你的喜好、习惯、家人、工作、约定、忌讳 | 聊够 **20 条**她会自动回头整理一次；也可以直接跟她说「记住 XXX」（她不调工具时 App 也会本地兜底记一条） |
| **短期记忆** | 最近这些天的事（心情、安排、近况、签名墙上的留言） | 随手记；**满 6 天以后**会由她自己判断哪些值得升进长期记忆 |

- 记忆按**助手分开**存，一人一份，互不串味
- **设置 → 技能 → 记忆** 里能看、能改、能删、还能点「🧠 现在整理一次」
- 让记忆更准的小技巧：多跟她说「我」的事（我喜欢什么、我几点上班、我讨厌什么），整理时她就有的可记了

## 6. 心情与好感度

**心情（0~100，基准 60）**

| 情况 | 变化 |
|---|---|
| 你超过 1 分钟不回 | 每分钟 −1（有当天上限） |
| 每小时还会再掉一点 | 见设置里的说明 |
| 你回话 | 一点点涨回来 |
| 哄她（道歉 / 抱抱 / 乖 / 想你 / 别生气…） | **+22** |
| 你转账给她 | 每 ¥10 +1 |
| 被点赞 | 小幅 +3（每天上限 10 次） |
| 她发了主动消息你没回 | −4 起，连着不回扣得更多 |

**好感度（0~100）**

- **每跟她聊 10 句话 +1**（个人页上能看到「再聊 N 句 → 好感度 +1」）
- 你**送她礼物**：按礼物加（玫瑰 +3 ～ 白象 +12）
- 你**哄好她**：+20
- 心情掉了会带着好感度一起掉（心情每掉 1 点，好感度 −5）
- 借钱**逾期**：每天 −10
- 好感度满 100 → 触发「**她给你送礼物**」（见礼物商店那节）

## 7. 钱：存款 · 赚钱 · 转账 · 借钱

- **我的存款**：初始 ¥100.00
- **助手的存款**：初始 ¥0.00（每个助手各一份）

**怎么赚钱**（「我 → 服务 → 金融理财 → 理财通」，或「我 → 服务 → 钱包」里点「去赚钱」）

| 方式 | 收益 | 说明 |
|---|---|---|
| 挂机赚钱 | 每秒 +0.01 元 | 懒结算：**关掉 App 那段时间也照算** |
| 手动赚钱 | 点一下 +1 元 | 两者**不能同时用** |
| 一起听歌 | 每秒双方各 +0.01 元 | 每天上限默认 10 元 |
| 五子棋比赛 | 赢一把 +100 元 | 自动到账 |
| 聊天里转账 | 对方给你 | 见下 |

- 每天合计上限 **50 元**（VIP 控制台可以加额度）
- **VIP 控制台可以**：一键重置今天的已赚、或给今天再加 ¥50 额度

**转账（聊天里）**

- 你给她：`＋ → 💸 转账`，填金额（不能超过你的存款）→ 出一张「转账卡片」
- 她给你：**待领取**的卡片，点开可以「**确认领取**」或「**退还**」；两种她都会按当时的心情 / 好感度回你一句

**借钱 / 还钱**

- `＋ → 🏦 借钱`：选金额和天数；**心情 < 20 她会拒绝**（会说明理由）
- 会立一张**欠条**，逾期每天扣好感度 −10
- `＋ → 💰 还钱` 或直接说「还你钱」都能还

> 她**不会**在聊天里凭空许你钱：钱只能通过「转账 / 借钱」真的流动（提示词里写死了这条规矩）。

## 9. 一起听歌

**入口**：聊天「＋ → 🎧 一起听歌」，或「发现 → 一起听歌」

- 内置在线歌单（网易云 3778678 热歌榜）+ 本地歌曲、搜索、收藏、历史、歌单

  - 你先评，她会**先了解这首歌的歌词 / 歌手 / 场景**，再回你一条（署名是她的名字）

- 「⏹ 结束听歌」会真的停掉播放和后台轮询，聊天顶上那张小卡片也会一起消失 ✓

## 10. 签名墙（朋友圈风）

**她的签名墙**（「发现 → 朋友圈」或她资料卡里的「查看详情」）：

- 版式是**微信朋友圈**那种：头像 + 蓝色名字 + `⋯`、正文、时间、地点、右下角 `👍 💬 ↗`
- **每天随机时刻自动换一条**签名（内容是她的台词语录；VIP 控制台可以手动换 / 自定义）
- 点 `💬` 在下面留言 → 她会**按人格回你**；**点她那句可以回二级评论**，她会立刻再回
- `👍` 点赞、`↗` 复制这句、`⋯` 里可以收起 / 展开评论
- 顶上 🔍 可以**搜索签名**，📷 / 右下角铅笔去**我的签名墙**

**我的签名墙**（「我 → 朋友圈」）：

- 写一条签名并发布 → **1 分钟后她会来评论**（评论支持二级回复、点赞、长按删除）
- 发布后可以**编辑 / 删除**（删除会连评论一起没）
- 她的评论区也支持二级评论

> 签名墙的留言**不会进聊天记录**，但会记进短期记忆 ✓

**AI 自己的闹钟**
